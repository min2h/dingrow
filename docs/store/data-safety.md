# Google Play 데이터 보안(Data safety) 답변 초안

> 근거: 앱 데이터는 Firebase(Firestore, asia-northeast3)에 동기화, 인증은 Firebase Auth(Google/Apple/익명), 구매는 Cloud Functions가 Play/App Store로 검증. 광고/분석 SDK 없음. 위치는 기기 → Open‑Meteo 직접(서버 저장 없음).

## 1. 데이터 수집 및 보안
| 질문 | 답 |
|---|---|
| 앱이 필수 사용자 데이터 유형을 수집하거나 공유하나요? | **예** (사용자 ID·이름·이메일, 구매 내역, 앱 데이터, 대략적인 위치) |
| 전송 중 데이터 암호화? | **예** (HTTPS) |
| 사용자가 데이터 삭제를 요청할 수 있나요? | **예** — 앱 내 설정 → 데이터 → '계정과 서버 데이터 삭제'(서버+계정 삭제), 이메일 요청. 삭제 안내 URL: https://min2h.github.io/dingrow/privacy/#delete |
| 계정 생성 방법 | Google / Apple / 게스트(Firebase 익명 계정) → "앱에서 계정을 만들 수 있음" **예**, 계정 삭제 URL에 위 링크 입력 |

## 2. 데이터 유형
| 유형 | 수집 | 공유 | 처리 | 선택/필수 | 목적 |
|---|---|---|---|---|---|
| 위치 › 대략적인 위치 | 예 | 아니요 (Open‑Meteo는 서비스 제공업체=공유 아님) | 임시 처리(저장 안 함) | **선택** | 앱 기능(날씨) |
| 개인 정보 › 사용자 ID | 예 | 아니요 | 저장 | 필수(게스트=익명 ID) | 앱 기능, 계정 관리 |
| 개인 정보 › 이름, 이메일 | 예 (Google/Apple 로그인 시 Firebase Auth) | 아니요 | 저장 | 선택 | 계정 관리 |
| 금융 정보 › 구매 내역 | 예 (상품 ID·토큰, 서버 검증) | 아니요 | 저장 | 선택 | 앱 기능, 사기 방지 |
| 앱 활동 › 기타 사용자 생성 콘텐츠(일정) / 앱 내 활동 | 예 (서버 저장/복원) | 아니요 | 저장 | 필수 | 앱 기능 |
| 앱 정보 및 성능, 기기 ID, 광고 ID | 아니요 | 아니요 | — | — | — |

※ Firebase(Google)는 서비스 제공업체(처리 위탁)이므로 '공유' 아님. 전송 중 암호화 예.

## 3. 기타 Play Console 앱 콘텐츠
| 항목 | 답 |
|---|---|
| 광고 포함 | **아니요** |
| 앱 액세스 권한 | 모든 기능 사용 가능(게스트 로그인으로 전부 접근 가능) — 심사자 계정 불필요 |
| 타겟층 | 만 13세 이상(권장: 13–15, 16–17, 18+ 선택 / 아동 대상 아님) |
| 뉴스 앱 | 아니요 |
| 정부 앱 | 아니요 |
| 금융 기능 | 없음 |
| 건강 | 없음 |
| 전체 화면 인텐트(USE_FULL_SCREEN_INTENT) | 알람 앱 용도로 신고: "사용자가 설정한 일정 알람을 잠금 화면에서 표시". 승인되지 않으면 매니페스트에서 제거 필요(아래 체크리스트 참고) |
| 정확한 알람(SCHEDULE_EXACT_ALARM) | 사용자가 설정한 일정 알림 시각을 정확히 지키기 위해 사용, 미허용 시 근사 알림으로 동작 |
| 위치 권한 | ACCESS_COARSE_LOCATION만, 포그라운드만(백그라운드 위치 없음) |
