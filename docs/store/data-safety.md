# Google Play 데이터 보안(Data safety) 답변 초안

> 근거: 딩그로는 자체 서버가 없고, 광고/분석 SDK가 없음. 위치는 기기 → Open‑Meteo로 직접 전송(날씨 조회), 로그인 정보는 기기에만 저장. Google의 정의상 "수집(collected)" = 앱에서 기기 밖(개발자 또는 제3자)으로 전송되는 데이터. 사용자의 요청에 따라 즉시 처리되고 저장되지 않는 전송도 기술적으로는 "수집"으로 볼 수 있으므로 위치는 보수적으로 '수집'으로 신고하는 것을 권장.

## 1. 데이터 수집 및 보안
| 질문 | 답 |
|---|---|
| 앱이 필수 사용자 데이터 유형을 수집하거나 공유하나요? | **예** (대략적인 위치 — 날씨용, 선택) |
| 전송 중 데이터 암호화? | **예** (HTTPS) |
| 사용자가 데이터 삭제를 요청할 수 있나요? | **예** — 앱 내 '몽이 처음부터 다시', 로그아웃, 앱 삭제. 삭제 안내 URL: https://min2h.github.io/dingrow/privacy/#delete |
| 계정 생성 방법 | Google 로그인 / Apple 로그인 / 게스트 (계정은 기기에만, 서버 계정 없음) → "앱에서 계정을 만들 수 있음"에 해당하면 **계정 삭제 URL**에 위 링크 입력 |

## 2. 데이터 유형
| 유형 | 수집 | 공유 | 처리 | 선택/필수 | 목적 |
|---|---|---|---|---|---|
| 위치 › 대략적인 위치 | 예 | 아니요 (Open‑Meteo는 서비스 제공업체=공유 아님) | 임시 처리(저장 안 함) | **선택** | 앱 기능(날씨) |
| 개인 정보 › 이름, 이메일, 사용자 ID | **아니요** (기기 밖으로 전송 안 함; Google/Apple 로그인 SDK가 처리) | 아니요 | — | — | — |
| 금융 정보 › 구매 내역 | **아니요** (결제는 Google Play가 처리, 구매 토큰은 기기에만 저장) | 아니요 | — | — | — |
| 앱 활동, 앱 정보 및 성능, 기기 ID | 아니요 | 아니요 | — | — | — |

※ 서버 검증/백엔드를 추가하면 이 표를 다시 작성해야 합니다(이름·이메일·사용자 ID·구매 내역 → 수집).

## 3. 기타 Play Console 앱 콘텐츠
| 항목 | 답 |
|---|---|
| 광고 포함 | **아니요** |
| 앱 액세스 권한 | 모든 기능 사용 가능(게스트 로그인으로 전부 접근 가능) — 심사자 계정 불필요 |
| 타겟층 | 만 13세 이상(권장: 13–15, 16–17, 18+ 선택 / 아동 대상 아님) |
| 뉴스 앱 | 아니요 |
| 정부 앱 | 아니요 |
| 금융 기능 | 없음 |
| 건강 | 없음 |
| 전체 화면 인텐트(USE_FULL_SCREEN_INTENT) | 알람 앱 용도로 신고: "사용자가 설정한 일정 알람을 잠금 화면에서 표시". 승인되지 않으면 매니페스트에서 제거 필요(아래 체크리스트 참고) |
| 정확한 알람(SCHEDULE_EXACT_ALARM) | 사용자가 설정한 일정 알림 시각을 정확히 지키기 위해 사용, 미허용 시 근사 알림으로 동작 |
| 위치 권한 | ACCESS_COARSE_LOCATION만, 포그라운드만(백그라운드 위치 없음) |
